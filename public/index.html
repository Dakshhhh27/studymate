How the LLM integration works

1. Answer questions. The Tutor tab sends your question, your topic/notes and the last 10 messages to the LLM, and streams the reply back.

2. Summarize topics. The Summary tab sends your notes with a prompt that fixes the sections (big idea, key points, key terms, recap) and your chosen length.

3. Generate practice quizzes. The Quiz tab asks the LLM for JSON (question, four options, correct index, explanation). The app parses it, scores your answers and shows explanations. Flashcards use the same JSON approach.

4. Prompt engineering. Every request shares one system prompt (tutor role, accuracy rules, grounding in your notes). Task prompts add a method (identify key ideas first), a strict output format, quality rules (understanding over trivia, plausible distractors) and, for quizzes and flashcards, a JSON-only schema.

5. Async calls and error handling. All calls go through one async callAI() function using async/await. It adds a 60-second timeout with AbortController, up to 2 retries with exponential backoff, validation of the returned JSON and clear messages for timeouts, rate limits, declined access and malformed output, with try/catch/finally so the buttons always re-enable.

Pipeline: user input → prompt builder (level, topic, notes) → LLM call → parse/stream → interactive UI. AI output can contain errors, so verify key facts.

Made for students, with care. I can slip up sometimes, so double-check anything important.
